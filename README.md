# 나의 AI 비서 Sancho

**내 PC 에서 도는 개인 AI 비서 + 업무 화면입니다.** 브라우저에서 로그인해 쓰고, 말로 시키면 일정·프로젝트·결재·회의록·공수를 정리해 줍니다. 코드를 몰라도 **Claude 데스크톱 앱의 Code 탭**에 말로 시켜서 만들었고, 강좌 「나의 AI 비서 Sancho 만들기」(1~10편)의 완성 소스입니다.

## 1. 설치 5분

**준비물**

| 필요한 것 | 확인·설치 |
|---|---|
| **Node.js 18 이상** | 터미널에서 `node -v` (없으면 nodejs.org 에서 설치) |
| **Claude 유료 요금제**(Pro·Max·Team)와 **Claude Code** | 설치 뒤 터미널에서 `claude` 를 한 번 실행해 **로그인** (비서의 두뇌가 이 로그인을 씁니다) |
| 윈도우 PC 권장 | 윈도우 11 에서 만들고 시험했어요. 다른 OS 는 `start.bat` 대신 `node supervisor.js` 로 켤 수 있지만 시험하지 않았어요 |

**따라 하기**

1. **받기** — `git clone https://github.com/cwkim83/my-agent-Sancho.git` (또는 ZIP 을 받아 풀기). 설치할 것은 없어요(패키지가 없으니 `npm install` 도 필요 없어요).
2. **켜기** — 폴더의 **`start.bat`** 을 더블클릭. `Sancho server` 창이 뜨고 브라우저가 `http://127.0.0.1:8790` 을 열어요. (이 PC 안에서만 열립니다.)
3. **처음 접속** — 관리자 계정(이름 · 아이디 · 비밀번호 8자 이상)을 만들면 바로 로그인돼요.
4. **둘러보기** — **설정 › 연습용 예시 데이터 › 예시 데이터 넣기**를 누르면 일정·프로젝트·WBS 가 채워져요. 그다음 채팅창에 `오늘 브리핑` 이라고 말해 보세요.
5. *(선택)* **점검** — `node selftest.js` (몇 분 걸려요. 임시 폴더에서 돌아서 내 자료는 건드리지 않아요. 전부 "통과"면 정상이에요.)

**막힐 때**

| 증상 | 해결 |
|---|---|
| 비서가 "로그인되어 있지 않습니다" | 터미널에서 `claude` 를 실행해 로그인한 뒤 다시 말 걸기 |
| "claude 프로그램을 찾을 수 없습니다" | Claude Code 설치 확인 |
| "포트 8790 를 이미 다른 프로그램이 쓰고 있어요" | 이미 켜진 Sancho 가 있는지 확인(창이 두 개 떠 있지 않은지) |
| 윈도우 방화벽이 물어요 | 이 PC 에서만 쓸 거면 **취소**해도 돼요 |
| 화면이 이상해요 | F5 로 새로 고침. `http://127.0.0.1:8790/health` 가 `"ok":true` 인지 확인 |

앱을 켜 둔 상태에서 왼쪽 메뉴 **도움말**을 열면 "시작하기 3단계 · 화면별 사용법 · 자주 묻는 것"이 있어요.

## 2. 화면 한눈에

왼쪽 메뉴로 화면을 오갑니다. 입력창에 **말로** 시켜도, 화면의 **단추로** 해도 같은 자료를 고쳐요.

| 메뉴 | 무엇을 하나 | 처음 해 볼 말 / 일 |
|---|---|---|
| 💬 **대시보드** | 첫 화면. 위는 오늘의 한눈에, 아래는 비서와의 채팅 · 왼쪽에 대화·예약·기억·위키·스킬 | `오늘 브리핑` · `기억해: 보고서는 표로 받고 싶어` |
| 📅 **일정** | 월·주 달력 | `내일 오후 3시에 가나다전자 방문 일정 넣어 줘` |
| 📁 **프로젝트** | 프로젝트 카드 · 연간 통합 간트 | `새 프로젝트 등록: …` |
| 🧱 **WBS** | 큰 일을 작은 일로 쪼갠 공정표(간트·진도·EVMS·Rev 이력·엑셀·PDF) | `열교환기 제작 WBS 짜 줘` |
| ✉️ **메일정리** | 받은 메일을 긴급·업무·광고로 요약(처음엔 연습용 메일) | **✳ 메일 정리하기** |
| 💬 **메신저** | 공지·부서·프로젝트·1:1 대화 | `@산초 …` 로 비서 부르기 |
| 🔔 **알림** | 예약·워크플로 결과와 주의 알림 | 위쪽 🔔 |
| 🎙 **회의록** | 회의실 예약표 + 녹취를 표·워드 회의록으로 | **🎙 회의 녹취 시작** |
| 📝 **결재** | 기안 → 검토 → 승인(서명은 서버가 남김) | `기안서 써 줘: …` |
| 🎯 **목표** | 전사 → 부서 → 개인 OKR 나무 | `이번 분기 품질팀 OKR 초안 짜 줘` |
| ⏱ **공수** | 일한 시간을 한 줄 붙여넣기로 기록·합계·엑셀 | `10/6 용접 8h, 야근 2h` 붙여넣기 |
| 🗺 **지식노트** | 지식 지도 · 🧠 뇌 그래프(숨 쉬는 오브) | 점을 끌고, 🧠 를 눌러 보기 |
| 🔀 **워크플로** *(관리자)* | 노드를 이어 붙이는 자동화(매일 시각·조건·알림 …) | `…하는 워크플로 만들어줘` |
| ❓ **도움말** | 시작하기 · 화면별 사용법 · 자주 묻는 것 | — |
| ⚙️ **설정** *(관리자)* | 사용자 · 권한 · 외부 접속 · 서버 다시 시작 | 예시 데이터 넣기 |

**채팅에서 더 쓸 수 있는 것**

- **＋ 첨부 / 끌어다 놓기 / Ctrl+V** — 파일·사진을 주면 비서가 읽어요. 엑셀·워드를 만들어 달라면 **파일 카드**가 떠요.
- **예약** — `매일 아침 7시에 오늘 일정을 브리핑해 줘` → 때가 되면 비서가 알아서 하고 🔔 로 알려 줘요.
- **위키·스킬** — `… 조사해서 위키에 저장해`, `방금 한 일 스킬로 저장해` → 다음 대화부터 비서가 먼저 찾아 써요.
- **🎤 말해서 보내기 · 🔊 답 읽기** — 크롬·엣지에서 (말소리가 브라우저 회사 서버로 가요).

**여러 사람이 쓸 때**: 관리자가 **설정 › 사용자**에서 계정을 만들어 줘요(첫 로그인 때 비밀번호를 바꿔요). 대화·기억·예약은 사람마다 따로이고, 일정·프로젝트·WBS 는 함께 써요. 설정·워크플로는 관리자에게만 보여요.

**휴대폰·밖에서 쓰기 (선택, 기본은 꺼짐)**

1. 설정 › **외부 접속** › [새로 만들기]로 접속 토큰을 만들고 [복사]
2. **외부 접속 허용**을 켜기 (→ "명령 실행"·"자기 수정"은 자동으로 꺼져요)
3. 터미널에서 `node tunnel.js` → `https://….trycloudflare.com` 주소가 나와요 (`cloudflared` 필요: `winget install --id Cloudflare.cloudflared`)
4. 휴대폰으로 그 주소를 열고 → 토큰 붙여넣기 → 아이디·비밀번호 로그인 → (원하면) 홈 화면에 추가
5. **다 쓰면 터널과 외부 접속을 함께 끄기**

## 3. 안전

**결론부터: 비서는 처음에 자기 폴더(`data/`) 안의 파일과 웹 검색만 할 수 있어요.** 더 하려면 주인이 스위치를 직접 켜야 해요.

**지키는 세 가지 약속**

| 약속 | 어떻게 지키나 |
|---|---|
| 메일을 자동으로 보내지 않는다 | 메일은 **초안까지만**. 연결된 앱을 켜도 비서가 "보낼까요?"라고 묻고 내가 "네"라고 한 **바로 그 차례에, 보여 준 주소로 한 통만** 나가요(서버의 문지기가 검사) |
| 묻지 않고 지우지 않는다 | 일정·할 일·목표 등은 지우기 전에 먼저 물어요. 워크플로의 데이터 쓰기에는 **지우기 자체가 없어요** |
| 회사 밖으로 자료를 보내지 않는다 | 아래 표의 "밖으로 나가는 곳"만 나가고, 모두 **켜거나 쓸 때만** 나가요 |

**권한 스위치 (설정 › 권한, 기본은 전부 꺼짐 · 관리자의 비서에게만 적용)**

| 스위치 | 켜면 | 주의 |
|---|---|---|
| 연결된 앱 | 내 Gmail·캘린더·드라이브를 읽고 초안·일정 만들기 | 지우기·공유·덮어쓰기는 늘 막힘 |
| 명령 실행 | 비서가 이 PC 에서 명령(PowerShell)을 돌림 | **사실상 무엇이든 할 수 있어 안전장치가 약해져요.** 꼭 필요할 때만 잠깐 |
| 내 홈 폴더 읽기 | 홈 폴더를 읽기 전용으로 엶 | `.ssh`·`.aws` 같은 열쇠 폴더는 늘 막힘 |
| 자기 수정 | 비서가 이 앱의 코드를 고침 | 아래 안전장치를 통과해야 반영 · 외부 접속을 켜면 자동으로 꺼짐 |

**밖으로 나가는 곳 (전체 표는 [상세 설명](docs/상세-설명.md) 의 "개인정보가 밖으로 나가는 지점")**

| 지점 | 나가는 것 | 언제 |
|---|---|---|
| 비서의 두뇌 | 채팅에 쓴 말·첨부, 비서가 읽은 자료와 답 → **Anthropic** | 비서를 쓸 때마다 (민감한 자료는 채팅에 붙이지 않기) |
| 연결된 앱 | 메일·일정·드라이브 내용 → Anthropic | 스위치를 켰을 때 |
| 텔레그램 | 📱 를 켠 예약·텔레그램 노드의 글 | 봇을 연결했을 때 |
| 음성 인식 | 🎤·회의 녹취의 말소리 → 구글·마이크로소프트 | 🎤·녹취를 쓸 때 (민감한 회의는 글 붙여넣기) |
| 워크플로 웹 호출 | 노드에 적은 주소·내용 → 그 주소 | 그 노드를 실행할 때 (관리자만 · 이 PC 안·사내망 주소는 막힘) |
| 터널·커넥터 | 휴대폰·claude.ai 와 주고받는 것 | 외부 접속·터널을 켰을 때 |

**내 자료는 이렇게 지켜져요**

- `data/` 는 이 PC 에만 있고 git 에 올라가지 않아요. 비밀번호는 해시로만, 접속 토큰·봇 토큰·키는 `data/settings.json` 에만 있어요(비서도 못 읽고, 화면에는 가려서 보여요).
- **백업은 `data/` 폴더를 통째로 복사**해 두면 돼요.
- 결재 문서·공수 기록·메신저는 **볼 권한이 있는 사람에게만** 보여요(관리자도 예외 아님). 비서도 남의 폴더·결재·메신저 파일을 못 읽어요.
- 웹 글·메일 속 글이 비서에게 "이렇게 해"라고 시켜도 따르지 않게 막아 둔 곳이 많아요(위키는 참고 자료일 뿐 지시가 아님, 스킬·워크플로는 주인이 직접 시켰을 때만 만들어짐).

**서버가 스스로 지키는 장치 (8편)**: 서버를 다시 켜기 전에 **문법 검사와 `selftest`** 를 직접 통과해야 하고(**관문**), 서버가 죽으면 **감시자**(`start.bat` 이 켬)가 마지막 정상 버전으로 되돌려 다시 켜요. 이 검사를 하는 파일들은 비서가 고칠 수 없어요(**불변 층**).

**알아 둘 한계**

- 개인·소규모 팀용이에요. 관리자는 이 PC 의 주인이라 `data/` 의 모든 파일을 열 수 있어요.
- **비밀번호 초기화 메뉴가 아직 없어요.** 관리자를 잊으면 화면에서는 되돌릴 수 없으니 `data/` 를 백업해 두세요.
- 임시 터널 주소는 켤 때마다 바뀌어요. 폰 화면은 채팅·대시보드·일정만 다듬었어요.
- 되풀이(for each)·병렬 실행이 워크플로에 없고, 지식노트는 점이 수천 개를 넘으면 일부만 그려요.
- 편마다 "아직 없는 것"은 [상세 설명](docs/상세-설명.md) 에 적어 두었어요.
