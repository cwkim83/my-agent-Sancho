# 나의 AI 비서 Sancho (my-agent)

코드를 몰라도 **Claude 데스크톱 앱의 Code 탭**에 말로 시켜서 만드는, 로그인 되는 개인 AI 비서 + 업무 대시보드입니다.
강좌 「나의 AI 비서 Sancho 만들기」의 완성 소스이고, 편마다 태그가 붙어 있습니다. 막히면 그 편의 태그를 열어 비교해 보세요.

| 태그 | 내용 |
|---|---|
| `ep1` | 청사진·구조도 · 로그인 화면 · 채팅창 · 두뇌(내 PC 의 Claude Code) · 기억 |
| `ep2` | 파일 저장소(data/db)·실시간 반영 · 예시 데이터 · 대시보드 · 일정(월/주 달력) · 비서가 업무 데이터 고치기(platform 스킬) |
| `ep3` | 프로젝트 메뉴(카드·연간 통합 간트) · WBS 공정표(표 바로 고치기·간트 끌기·EVMS·S-곡선) · Rev 이력·엑셀·PDF·읽기 전용 공유 링크 · 비서가 WBS 짜기(wbs 스킬) |
| `ep4` | 예약(data/schedule.json: daily·weekly·once·every) · 30초 시계가 때가 된 지시문을 새 세션의 두뇌에 보냄 · 결과는 data/journal/<날짜>.md 와 알림(notices) · 놓친 예약은 한 번만·겹침 방지 · 비서가 말로 예약 만들기 · 위쪽 🔔 알림(안 읽은 수 배지·목록·누르면 결과 전체) · 채팅 왼쪽 예약 칸(켬/끔·지금 실행·삭제) |

## 실행

1. 준비: Node.js 18 이상 · Claude 유료 요금제(Pro·Max·Team) · 이 PC 에서 Claude Code 로그인
2. `start.bat` 을 더블클릭 → 브라우저에서 `http://127.0.0.1:8790` (이 PC 안에서만 열립니다)
3. 처음 열면 관리자 계정을 만듭니다. 점검은 `node selftest.js`

- 외부 패키지가 없습니다(Node.js 내장 기능만). 데이터는 `data/` 폴더의 파일이고 git 에 올리지 않습니다.
- 두뇌는 따로 API 키를 사지 않고, 이 PC 에 로그인한 Claude Code 를 그대로 씁니다.
