# 나의 AI 비서 (my-agent) — Sancho 청사진

## 1. 한 줄 소개
내 PC에서 도는 **개인 AI 비서 + 업무 대시보드**. 브라우저에서 로그인해서 쓴다.

## 2. 핵심 원칙
| 항목 | 결정 | 쉬운 설명 |
|---|---|---|
| 두뇌 | 이 PC에 설치된 **Claude Code**를 그대로 사용 | 내 구독 로그인으로 동작. **API 키(외부 서비스 접속용 비밀번호)는 쓰지 않음** |
| 데이터 | `data/` 폴더의 **JSON·마크다운 파일** | 데이터베이스 서버(자료를 따로 관리하는 프로그램)를 두지 않고 그냥 파일로 저장 |
| 보안 | `data/`는 **git에 올리지 않음** | 개인·업무 자료가 저장소(코드 기록)에 섞여 나가는 것을 막음 |
| 의존성 | **외부 패키지 없이 Node.js 내장 기능만** | 남이 만든 부품(라이브러리)을 가져다 쓰지 않아 설치·보안 부담이 적음 |
| 실행 위치 | 내 PC 안 | 서버를 따로 빌리지 않음 |

## 3. 화면 구성
- **왼쪽 메뉴**: 대시보드 · 일정 · 프로젝트 · WBS(작업 분해표: 큰 일을 작은 일로 쪼갠 목록) · 메일 · 메신저 · 알림 · 회의록 · 결재 · 목표 · 공수(일에 쓴 시간) · 지식노트 · 워크플로(반복 업무 자동화 순서) · 설정
- **대시보드 자리에 AI 채팅**: 첫 화면에서 바로 비서에게 말을 건다.

## 4. 절대 안 할 것 (안전 규칙)
1. **메일 자동 발송 금지** — 초안만 만들고, 보내는 건 항상 내가 직접 확인 후.
2. **묻지 않고 파일 삭제 금지** — 지우기 전에 반드시 허락을 받는다.
3. **회사 밖으로 자료 전송 금지** — 사내 자료를 외부로 보내지 않는다.

## 5. 로드맵 (총 10편)
| 편 | 내용 | 쉬운 설명 |
|---|---|---|
| 1 | 로그인 · 채팅 · 두뇌 · 기억 | 로그인하고 AI와 대화, 이전 대화를 기억하게 만들기 |
| 2 | 대시보드 · 일정 | 한눈에 보는 첫 화면과 캘린더 |
| 3 | 프로젝트 · WBS | 프로젝트를 만들고 할 일을 쪼개 관리 |
| 4 | 예약 · 알림 | 정해진 시간에 일을 시키고 알려 받기 |
| 5 | 메일 · 문서 | 메일 읽기·요약·초안 작성, 문서 다루기 |
| 6 | 메신저 · 회의록 | 메시지 정리, 회의 내용 기록·요약 |
| 7 | 결재 · 목표 · 공수 | 결재 현황, 목표 관리, 업무 시간 기록 |
| 8 | 안전장치 | 위 "안 할 것"을 실제로 막는 장치와 점검 |
| 9 | 밖에서 쓰기 · 커넥터 · 음성 | 외출 중 접속, 다른 서비스 연결(커넥터), 말로 지시 |
| 10 | 지식노트 · 워크플로 | 메모를 쌓아 두고 반복 업무를 자동화 |

> **진행 상태: 1~10편 모두 구현했습니다.** 편별 요약은 [README.md](../README.md), 자세한 규칙은 [상세-설명.md](상세-설명.md). 계획과 달라진 점: 왼쪽 메뉴의 "메일"은 "메일정리" 하나로 합쳤고, 10편에는 지식노트·워크플로 외에 위키·스킬(채팅 왼쪽 칸)과 **도움말** 메뉴가 더해졌습니다.
