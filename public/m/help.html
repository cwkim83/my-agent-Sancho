도움말

Sancho 는 내 PC 에서 도는 AI 비서 + 업무 화면이에요. 코드를 몰라도, 말로 시키면 됩니다. 처음이라면 아래 3단계부터 따라 해 보세요.

찾는 내용이 없어요. 다른 낱말로 찾아 보세요.

시작하기 3단계면 충분해요

1

비서에게 말 걸어 보기

첫 화면(대시보드) 아래 입력창에 말을 쓰고 Enter. 입력창 위의 단추(오늘 브리핑 …)를 누르면 말이 채워져요. 답이 오는 동안 "파일 읽는 중" 같은 표시가 떠요.

2

예시 자료로 둘러보기

관리자라면 설정 › 연습용 예시 데이터 › 예시 데이터 넣기 를 누르세요. 일정·프로젝트·할 일·WBS 가 채워져서 각 화면이 어떻게 생겼는지 바로 볼 수 있어요. 이미 있는 자료는 그대로 두고 예시만 더해요. 일반 사용자는 관리자에게 부탁하세요.

3

반복 업무를 맡기기

자주 하는 일은 말로 맡겨 두세요. 비서가 기억하고, 때가 되면 알아서 하고, 결과를 🔔 알림으로 알려 줘요.

💡 비서가 답을 안 하거나 "로그인되어 있지 않습니다"라고 하면 아래 자주 묻는 것의 첫 항목을 보세요.

화면별 사용법 누르면 펼쳐져요 · 파란 말풍선을 누르면 채팅 입력창에 채워져요 (보내기는 직접)

💬 대시보드 · 채팅첫 화면. 위는 오늘의 한눈에, 아래는 비서와의 대화

이렇게 써요

  • 위쪽 카드: 오늘 일정 · 진행 중 프로젝트 · 7일 안 마감 할 일 · 안 읽은 알림 · 결재할 문서. 누르면 해당 화면으로 가요.
  • ＋ 새 대화로 새 이야기를 시작하고, 왼쪽 목록에서 지난 대화를 다시 열어요. 비서는 같은 대화 안의 앞 말을 기억해요.
  • ＋ 단추(또는 파일을 끌어다 놓기, Ctrl+V)로 파일·사진을 붙이면 비서가 읽어요. 엑셀·워드를 만들어 달라고 하면 채팅에 파일 카드(보기·열기·받기)가 떠요.
  • 왼쪽 아래 칸: 예약(때가 되면 시킬 일, 켬/끔·지금 실행) · 기억(비서가 알아 둔 것) · 위키(비서가 정리해 둔 지식) · 스킬(저장한 절차). 이름을 누르면 내용이 보이고 ✕ 로 지워요.
  • 🎤 를 누르고 말하면 말이 끊긴 뒤 자동으로 보내져요(크롬·엣지). 답을 소리로 듣고 싶으면 🔊 답 읽기. 마이크 소리는 브라우저 회사 서버로 가는 점은 알아 두세요.

비서에게 이렇게 말해 보세요

📅 일정월·주 달력으로 보는 일정

이렇게 써요

  • 월 / 주 단추로 보기를 바꾸고, ‹ › 로 달을 넘기며, 오늘로 돌아와요.
  • ＋ 추가로 일정을 넣어요(제목·종류·날짜·시각·장소). 일정을 누르면 고치거나 지울 수 있어요.
  • 회의실 예약도 여기에 같이 보여요(예약은 회의록 화면에서만 만들고 바꿔요).

  • 프로젝트가 카드로 보여요(고객·상태·진도율·기간·담당). 아래 연간 통합 간트에서는 모든 프로젝트의 기간을 한 해 달력 위에서 한눈에 봐요. 올해 단추로 돌아와요.
  • + 새 프로젝트로 만들고, 카드를 누르면 그 프로젝트의 WBS(작업 분해표)가 열려요.

  • 💾 Rev 저장으로 그때의 모습을 남기고, 📜 이력에서 옛 Rev 를 보거나 되돌려요.
  • 📊 엑셀 · 📄 PDF(🖨 인쇄) · 🔗 공유 링크(로그인 없이 읽기만 되는 주소 — 쓸 때만 만들고 링크 끊기로 닫아요)를 쓸 수 있어요.

🗺 지식노트지식 지도와 🧠 뇌 그래프

  • 🗺 지식 지도: 프로젝트·할 일·회의·결재·위키·사람이 점으로, 서로 언급하면 선으로 이어져요. 점을 끌어 옮기고, 휠로 확대하고, 점을 누르면 미리보기와 이어진 점, 열기 →가 떠요. 위쪽 색 단추로 종류를 숨기고, 점 찾기로 이름을 찾아요.

내 자료는 어디에 저장되나요? 밖으로 나가나요?

대화·기억·일정·프로젝트 같은 자료는 모두 이 PC 의 data/ 폴더에 파일로 있고, git 에도 올라가지 않아요. 백업은 그 폴더를 통째로 복사해 두면 돼요.

다만 비서에게 보낸 말과 비서가 읽은 자료는 Anthropic(Claude)으로 가요. 그 밖에 나가는 곳(텔레그램·음성 인식·터널 등)은 README 의 "3. 안전"의 "밖으로 나가는 곳" 표에 모아 두었어요. 모두 켜거나 쓸 때만 나가요.

비서가 메일을 마음대로 보내거나 파일을 지우나요?

아니요. 세 가지는 지키도록 만들었어요. ① 메일은 초안까지만 만들어요. 연결된 앱을 켜도 비서가 "보낼까요?"라고 묻고 내가 "네"라고 한 바로 그 차례에, 보여 준 주소로 한 통만 나가요. ② 지우기 전에는 항상 먼저 물어요(일정·할 일·목표 등). ③ 사내 자료를 밖으로 보내지 않아요(웹 호출·텔레그램 노드는 내가 직접 넣어야만 나가요).

예약한 일이나 워크플로가 안 돌아요
  • 예약·워크플로는 이 PC 가 켜져 있고 서버가 돌고 있을 때만 돌아요(start.bat 창이 떠 있어야 해요).
  • 예약 칸의 스위치 또는 워크플로의 자동 실행 켬이 켜져 있는지 보세요.
  • 꺼져 있는 동안 놓친 회차는 켜지면 한 번만 돌아요(몰아서 돌지 않아요).
  • 실패하면 🔔 알림에 이유가 와요. 워크플로는 실행 기록에서 어느 단계가 ❌ 인지 보여요.
휴대폰에서도 쓸 수 있나요?

네. 화면이 좁으면 ☰ 메뉴와 아래 탭(채팅·대시보드·일정)으로 바뀌고, 홈 화면에 앱처럼 추가할 수 있어요. 밖(휴대폰)에서 열려면 관리자가 설정 › 외부 접속을 켜고 터널(node tunnel.js)을 켜야 해요. 기본은 꺼짐이고, 접속 토큰과 로그인 두 겹으로 지켜요. 다 쓰면 터널과 외부 접속을 함께 끄세요. 자세한 순서는 README 의 "2. 화면 한눈에" 아래 "휴대폰·밖에서 쓰기"에 있어요.

어떤 메뉴가 안 보여요 (설정·워크플로)

설정과 워크플로는 관리자만 보여요. 일반 사용자는 대화·일정·프로젝트·WBS·메일정리·메신저·회의록·결재·목표·공수·지식노트를 모두 쓸 수 있어요.

비밀번호를 잊었어요

아직 화면에서 비밀번호를 초기화하는 메뉴는 없어요. 일반 사용자는 관리자에게 새 계정(임시 비밀번호)을 부탁하세요(첫 로그인 때 직접 바꾸게 돼요). 관리자 본인이 잊었다면 지금은 화면에서 되돌릴 방법이 없으니, 이 PC 의 data/ 폴더를 백업해 두고 새로 시작해야 해요. 비밀번호는 해시로만 저장돼서 파일을 열어도 알 수 없어요.

서버를 껐다 켜고 싶어요 / 코드를 고쳤는데 반영이 안 돼요

켜기는 start.bat 더블클릭, 끄기는 Sancho server 창에서 Ctrl+C 예요. 서버는 감시자가 지켜봐서, 비정상으로 죽으면 마지막 정상 버전으로 되돌려 다시 켜요. 설정의 서버 다시 시작은 서버가 직접 검사(문법·selftest)해서 통과해야만 다시 켜요. 몇 분 걸릴 수 있어요.

비서가 앱 코드를 마음대로 고치나요?

아니요. 자기 수정 스위치는 기본 꺼짐이고 관리자만 켤 수 있어요. 켜도 검사를 통과해야 반영되고, 실패하면 원래대로 되돌려 보존해 둬요. 그리고 안전장치 파일(감시자·관문·메일 문지기·selftest)은 비서가 고칠 수 없어요.

연습용 메일과 진짜 메일은 어떻게 다른가요?

설정 › 권한의 연결된 앱이 꺼져 있으면 연습 모드예요. 가상 회사 "가나다전자"의 연습용 메일로만 동작하고 내 Gmail 은 건드리지 않아요. 켜면 내 Gmail 받은편지함을 읽어요. 일반 사용자의 메일정리는 늘 연습 모드예요.

비서가 같은 걸 자꾸 잊어요 · 배운 걸 오래 쓰게 하려면?
  • 오래 쓸 사실은 "기억해: …" 라고 말하면 왼쪽 기억 칸에 남아요(비밀번호 같은 민감한 정보는 기억하지 않아요).
  • 조사한 내용은 "… 위키에 저장해", 방금 한 일의 순서는 "방금 한 일 스킬로 저장해"(관리자). 다음 대화부터 비서가 먼저 찾아 써요.
  • 대화는 새로 시작해도 기억·위키·스킬은 남아요.
화면이 이상하거나 오래된 것처럼 보여요

브라우저를 새로 고침(F5)해 보세요. 그래도 이상하면 서버 창(Sancho server)에 오류가 있는지 보고, http://127.0.0.1:8790/health 가 "ok":true 로 답하는지 확인하세요.
